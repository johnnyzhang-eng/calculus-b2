# 高数B(2)学习讲义

手机和电脑均可访问：<https://johnnyzhang-eng.github.io/calculus-b2/>

按老师23课顺序整理，包含基础衔接、定积分与应用、微分方程、多元微分、二重积分、独立练习和卡点视频入口。先打开“路线”，按起点检查和模块任务学习。

网页本身不依赖外部资源；视频链接需要联网。也可以下载 `index.html` 离线打开。阅读位置和自评保存在当前浏览器，不在不同设备间同步。

## 发布

GitHub Pages从`main`分支根目录发布，入口为`index.html`。更新讲义后提交推送即可部署。

## 第三方组件

公式使用KaTeX 0.19.0及其字体，许可见`KaTeX-LICENSE.txt`。本仓库包含重新排版的讲义，不包含原始课堂图片、登录信息或账号凭证。
